# 兵种定位与平衡

## 平衡原则

第一优先级是同一阶段内的均衡。处于同一阶段的兵种，在相同金币和补给投入下，应保持接近的综合战力；不能因为某个兵种拥有更高生命、输出、移速、射程或特殊效果，就在大多数场景中同时占据优势。每个兵种必须保留清晰特点，优势要通过其他指标、价格或适用场景来交换。

目标是在金币、补给、输出、耐久、机动及特殊效果之间形成可理解的取舍，让每个单位都具有购买理由。评估顺序是：先比较同阶段的每金币战力和每补给战力，再检查克制关系、机动性、射程、特殊效果和持续作战能力；最后才比较跨阶段的绝对强度。重甲压制轻甲、远程压制重甲、轻甲依靠速度接近远程；有掩护的远程不必输给所有轻甲组合。阶段为用途标签，并非解锁限制。

## 区域火炮技能

区域火炮是独立的一次性技能，不属于兵种，也不占 roster 名额。按钮消耗2000金币，冷却80秒，自动取当前交战区域的横向中心，覆盖固定的1100宽、500高战场条带。视觉上每轮约24枚导弹交错落下，单枚经历高空慢速、中段加速和末端高速的下坠过程；伤害仍持续5秒、分5次造成，每次为总伤害的五分之一，单位在中途死亡后不会继续受伤。前期目标受到足以击杀满血单位的伤害；中前期和中后期目标均受到最大生命值84%的总伤害；后期目标受到约24%最大生命值伤害。爆炸范围内的己方士兵受到12%最大生命值的误伤；技能不会把军营或大本营作为目标。

## 本轮调整

- 弓箭手替换武士，作为前期远程单体单位；剑兵继续承担防守前排，弓箭手用较低生命和较高射程换取对重甲的持续压制。
- 阶段分为前期、中前期、中后期和后期；忍者、重甲长矛兵、武僧属于中前期，吸血鬼、骑兵、法师属于中后期。阶段描述上场节奏，不改变解锁条件。中前期价格为100–450金币，中后期为600–800金币，后期保持1500 / 1500 / 1800；神秘兵种作为特殊类别维持1000金币。忍者虽然只需100金币，但消耗2补给、生命只有90且闪现有4.5秒冷却，定位是专门切入弓箭手的脆弱战术单位。远程单位移速低于重甲，弓箭手改为100金币和135射程，并降低生命、伤害和攻击频率，换取后排输出但无法靠速度永久逃离重甲。开局金币仍为400，可以选择少量忍者抢先压制弓箭手，也可以保存资源组织前排。
- 每轮补给调整为30；弓箭手消耗3补给，一轮最多部署10个；奇异博士和恐惧领主一轮最多部署5个，至高领主最多部署4个。
- 每方最多同时拥有30名存活士兵；满员时停止招募且不扣资源，出现空位后继续。
- 每20秒进入下一轮，大本营保障收入从200开始、每轮增加50并持续增长；每点存活补给产生4金币收益，阵亡后停止。金币负责持续出兵，30点补给和30人上限负责限制中后期单位数量，大本营保障收入确保劣势方仍能重建军队。
- 区域火炮价格调整为2000，作为需要积攒资源的战术技能。

## 验证与限制

运行 node scripts/balance-review.mjs 可生成 artifacts/balance-identities.json。对战使用原战斗引擎，关闭自动招募，在中央预布阵，双方预算相同但可能有买不起整兵的余额；每项交换阵营、运行两个种子。部分项目加入同等预算的弓箭手掩护。它是定位诊断，不代表线上胜率，也不覆盖持续收入、补给紧张和不同阵型。接近敌方建筑作战范围时测试提前终止并标记boundaryReached，该结果只代表截断时状态，不算歼灭胜利。

完整对局与桌面测试用于检查退化，不作为所有兵种已完全平衡的证明。

后期单位价格调整为 1500 / 1500 / 1800；对称 AI 压力测试使用双方动态克制选兵，城墙争夺阶段不应出现后期单位。运行 `node scripts/economy-stress.mjs 300` 可复现 300 局检查，要求异常率低于 5%。本轮固定种子普通对局在 694 秒（约11分34秒）自然结束；双方存活单位峰值均受30人上限约束。

## v1.2.22 中期阶段与经济校准

- 将中期明确拆成中前期（忍者、重甲长矛兵、武僧）和中后期（吸血鬼、骑兵、法师）；神秘兵种单列为特殊类别。
- 依据100个固定种子的普通难度对称AI压力模拟，采用上表价格与补给。相较原版，15分钟内未能推倒首座军营的局数从9/100降至2/100；成功局的军营倒塌中位数从358.25秒变为393.5秒。5分钟前倒墙局数为37/100，原版为35/100，早期极端局仍需关注。
- 两组模拟均未观察到后期英雄在首座军营倒塌前参战。候选组在军营倒塌时，平均存活军队约20名前期、6名中前期、4名中后期单位，没有后期英雄。
- 该压力模拟只评估军营争夺阶段；候选组在首座军营倒塌时停止，不能据此推断后半场大本营决战时长。原版完整对称AI组在15分钟内没有自然结束的对局，实际玩家对局和非对称AI配置仍需另行观察。
